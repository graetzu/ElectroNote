# InfiniteNote (formerly ElectroNote)

> Das moderne, grenzenlose Notizbuch für iPad und Mac mit unendlichem A4-Canvas, nativer Apple Pencil Unterstützung, Whiteboard, MindMaps, OCR und flexibler Cloud-Synchronisation (iCloud / Nextcloud).
